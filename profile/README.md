## ✦ Mission

Velorona helps telecom and critical-infrastructure operators detect early network degradation before customer impact, SLA exposure, or NOC escalation.

---

## ✦ Current Focus

Velorona's active validation focus is **microwave link degradation**, using controlled testbed data to observe how link behavior changes under baseline and degraded conditions.

- **Microwave** — current validation focus
- **Wireless** — near-term operational relevance
- **Transport** — backhaul and packet-path degradation patterns
- **Satellite / NTN** — future scope
- **Edge Deployment** — read-only sidecar and shadow-mode operation

---

## ✦ Deployment Principles

- Read-only
- Out-of-band
- No control-plane changes
- No DPI
- No PII
- Shadow-mode first
- Operator decision support
