# Security policy

This is the default security policy for AID Edge Inc. repositories that do not define their own.

## Reporting a vulnerability

Please report suspected vulnerabilities **privately**. Do not open a public issue or pull request with exploit details.

- Preferred: use **GitHub private vulnerability reporting** on the affected repository (Security tab → *Report a vulnerability*), where enabled.
- Otherwise e-mail **sara@aidedgeinc.com** with the repository, the affected version or URL, and steps to reproduce.

Do not include credentials, personal data or operator data in a report. If you have accessed such data, stop and tell us what and where.

## Scope

Public repositories under `AIDEdgeInc-Lab`, the published Python packages (`aei-*`), the Velorona QGIS plugin, and the
sites `velorona.ai`, `map.velorona.ai` and `aidedgeinc.com`. Velorona is a read-only, out-of-band analysis tool; reports
about any path that could write to, or alter the control plane of, an operator network are the highest priority.

## Supported versions

The latest released version of each package or plugin.

## What to expect

We will acknowledge a report, investigate, and tell you the outcome. Please allow reasonable time before public
disclosure. No bug bounty is offered.
